# Як долучитися до розвитку Ковчега

[English](../../CONTRIBUTING.md)

Дякуємо за допомогу. Найбільше Ковчег покращується завдяки реальному використанню: запитанням, на які він не зміг відповісти, документам, які він погано прочитав, комп'ютерам, на яких він працював надто повільно.

## Як допомогти

- **Повідомляйте про збої**, додаючи запитання, модуль і, якщо можете ними поділитися, відповідні документи. Проблеми, що стосуються безпеки людей, позначайте міткою `safety`.
- **Бенчмарки:** запустіть `kovcheg doctor`, заміряйте час `kovcheg ask` на своєму обладнанні й надішліть результати.
- **Набори для оцінювання:** файли JSONL із запитаннями та документом (і сторінкою), що на них відповідає, для документів із відкритою ліцензією. Вони роблять зміни в пошуку вимірюваними (`kovcheg eval`).
- **Код:** читачі для нових форматів, інтеграція OCR, швидше індексування на слабких процесорах, переклади інтерфейсу.

## Основні правила

1. **Насамперед офлайн.** Жодна функція не може вимагати доступу до мережі під час роботи, і ніщо не може надсилати дані «додому».
2. **Деградувати, а не відмовляти.** Кожен необов'язковий компонент (модель ембедингів, реранкер, мовна модель, читачі документів) має залишатися необов'язковим. `pip install kovcheg` лише з numpy має й далі працювати.
3. **Чесні відповіді.** Зміни в промптах чи ранжуванні мають зберігати точність посилань і не повинні послаблювати перевірку доказів.
4. **Вимірюйте.** Твердження про кращий пошук потребують результатів `kovcheg eval` до і після змін на спільному наборі для оцінювання.
5. **Жодних ваг моделей чи документів, захищених авторським правом, у репозиторії.**

## Розробка

```bash
git clone https://github.com/sashapiscivca-svg/Kovcheg && cd Kovcheg
python3 -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
pytest -q                 # швидко, з фіктивними моделями; нічого не завантажує
ruff check src tests
```

Код і коментарі пишемо англійською. Документацію для користувачів підтримуємо англійською (`docs/en`, `*.md`) та українською (`docs/uk`, `*.uk.md`); якщо можете оновити лише одну мову, зазначте це в pull request. Роблячи внесок, ви погоджуєтеся, що він ліцензується за ліцензією MIT.
