# Налаштування

[English](../en/configuration.md) · [Зміст документації](README.md)

Усі налаштування зберігаються в `kovcheg.toml` у домашній теці Ковчега. Кожен ключ необов'язковий; `kovcheg init` створює файл із типовими значеннями та коментарями. Готові файли для кожного рівня обладнання лежать у [`examples/`](../../examples). Шляхи задаються відносно домашньої теки. Якщо `kovcheg.toml` немає, Ковчег і далі читає `config.json` прототипу.

Будь-який ключ можна перевизначити для однієї команди за допомогою `--set section.key=value`, наприклад `kovcheg ask "..." --set llm.temperature=0`.

## `[embedding]`

| Ключ | Типово | Значення |
|---|---|---|
| `model` | `"models/bge-m3"` | тека з BAAI/bge-m3; `""` вимикає семантичний пошук (лише BM25) |
| `device` | `"cpu"` | `"cuda"`, якщо є GPU і збірка PyTorch із CUDA |
| `fp16` | `false` | половинна точність; корисна лише на GPU |
| `batch_size` | `16` | кількість фрагментів у пакеті під час індексування; зменште на комп'ютерах із малим обсягом оперативної пам'яті |
| `max_length` | `1024` | кількість токенів на фрагмент під час індексування |
| `query_max_length` | `256` | кількість токенів на запитання |

## `[rerank]`

| Ключ | Типово | Значення |
|---|---|---|
| `model` | `"models/bge-reranker-v2-m3"` | тека з крос-енкодером; `""` вимикає його |
| `enabled` | `true` | вмикає чи вимикає реранкінг без видалення моделі |
| `top_n` | `20` | кількість кандидатів, які оцінюються для кожного запитання; час зростає лінійно |
| `max_length` | `512` | кількість токенів на пару «запитання + уривок» |
| `batch_size` | `8` | кількість пар у пакеті |
| `min_score` | `-6.0` | логіт, нижче від якого найкращий уривок вважається ознакою «немає доказів»; збільште його (напр., до −3), щоб бути суворішим |

## `[llm]`

| Ключ | Типово | Значення |
|---|---|---|
| `model` | `""` | шлях до файлу `.gguf`; `""` — режим «лише пошук». Для файлів, розбитих на частини, укажіть першу частину |
| `context_window` | `4096` | у токенах; джерела обрізаються, щоб уміститися в `context_window − max_tokens` |
| `max_tokens` | `600` | максимальна довжина відповіді |
| `temperature` | `0.1` | низькі значення тримають відповіді близько до джерел |
| `top_p` | `0.9` | nucleus-семплінг |
| `repeat_penalty` | `1.1` | штраф за повторення |
| `threads` | `0` | потоки CPU; 0 — типове значення llama.cpp (фізичні ядра) |
| `gpu_layers` | `0` | кількість шарів, перенесених на GPU, якщо llama.cpp зібрано з підтримкою GPU |
| `chat_format` | `""` | перевизначає шаблон чату; `""` — шаблон, збережений у файлі GGUF |

## `[retrieval]`

| Ключ | Типово | Значення |
|---|---|---|
| `top_k` | `8` | кількість джерел, які показуються й передаються мовній моделі |
| `candidates` | `50` | кількість кандидатів від кожного методу пошуку до злиття |
| `rrf_k` | `60` | константа Reciprocal Rank Fusion |
| `weights` | `{ dense = 1.0, sparse = 0.6, bm25 = 0.8 }` | внесок кожного методу пошуку в об'єднаний ранг |
| `max_per_document` | `3` | різноманітність: щонайбільше стільки джерел з одного документа |
| `context_neighbors` | `1` | кількість фрагментів до і після кожного джерела, що додаються до контексту мовної моделі; 0 вимикає |
| `dedup_threshold` | `0.95` | косинусна подібність, вище від якої два уривки вважаються дублікатами |

## `[chunking]` (діє під час збирання; після зміни модулі буде переіндексовано під час наступного збирання)

| Ключ | Типово | Значення |
|---|---|---|
| `target_chars` | `1000` | бажана довжина фрагмента |
| `max_chars` | `1600` | жорстка верхня межа |
| `overlap_sentences` | `1` | кількість речень, що повторюються в сусідніх фрагментах |
| `min_chars` | `40` | коротші залишки об'єднуються з попереднім фрагментом |

## `[ui]`

| Ключ | Типово | Значення |
|---|---|---|
| `host` | `"127.0.0.1"` | `"0.0.0.0"` робить інтерфейс доступним для інших пристроїв у мережі (без автентифікації) |
| `port` | `8501` | |
| `language` | `"uk"` | мова інтерфейсу: `uk` або `en` |

## Змінні середовища

- `KOVCHEG_HOME`: домашня тека (застаріла назва `KOVCHEG_ROOT` також приймається).
- Перед завантаженням моделей ембедингів Ковчег задає `HF_HUB_OFFLINE=1` і `TRANSFORMERS_OFFLINE=1`, тож жодних спроб доступу до мережі не відбувається.
