# Використання Ковчега: командний рядок і вебінтерфейс

[English](../en/usage.md) · [Зміст документації](README.md)

Кожна команда приймає `--home DIR` (типово: `$KOVCHEG_HOME`, а якщо його не задано — поточна тека) і `--set KEY=VALUE`, щоб перевизначити налаштування для одного запуску, наприклад `--set llm.model=models/other.gguf` або `--set rerank.enabled=false`.

## Команди

| Команда | Що робить |
|---|---|
| `kovcheg init` | створює `modules/`, `sources/`, `models/`, `keys/` і `kovcheg.toml` з коментарями |
| `kovcheg build NAME [--source DIR] [--title T] [--description D] [--language L] [--rebuild] [--no-embed] [-q]` | створює або оновлює модуль (базу знань) із `sources/NAME/` (або `--source`) |
| `kovcheg search QUESTION [-m MODULE]… [-k N] [--no-rerank] [--json]` | показує найдоречніші уривки |
| `kovcheg ask QUESTION [-m MODULE]… [-k N] [--no-rerank] [--search-only] [--json]` | відповідає з пронумерованими джерелами |
| `kovcheg ui [--host H] [--port P]` | запускає вебінтерфейс |
| `kovcheg modules` (`list`) | модулі зі станом цілісності, розміром і енкодером |
| `kovcheg inspect NAME` | маніфест, файли й документи модуля |
| `kovcheg verify [NAME] [--quick]` | перевіряє підписи та хеші файлів (`--quick`: лише розміри) |
| `kovcheg keygen` / `kovcheg sign NAME` | створює пару ключів для підпису / підписує модуль |
| `kovcheg migrate NAME [--delete-old]` | перетворює модуль прототипу (`search_bge.db`) у формат v2 без повторного кодування |
| `kovcheg doctor [--json]` | перевіряє комп'ютер, бібліотеки, моделі й модулі; рекомендує рівень обладнання |
| `kovcheg eval FILE.jsonl [-m MODULE]… [-k N] [--json]` | вимірює якість пошуку |

Без `-m` пошук ведеться в усіх модулях, цілісність яких не INVALID.

**Коди завершення:** 0 — успіх; 1 — помилка (зокрема модуль зі станом INVALID у `verify`); 2 — помилка використання; 3 — немає доказів (нічого доречного не знайдено); 4 — бракує компонента (модуля, моделі, бібліотеки чи ключа). На них можна покладатися у скриптах.

## Вивід

```
$ kovcheg ask "як зупинити сильну кровотечу" -m first-aid
Притисніть рану чистою тканиною і тисніть щонайменше 10 хвилин [1]. Якщо пряме притискання не допомагає,
накладіть турнікет на 5–7 см вище рани і запишіть час [1].

Sources:
[1] Зупинка кровотечі — Сильна кровотеча з кінцівки  (first-aid: bleeding.md)
    Притисніть рану чистою тканиною і тисніть сильно щонайменше 10 хвилин. …
```

З `--json` вивід — це один JSON-об'єкт із полями `question`, `status`, `answer`, `sources` (кожне джерело має `n`, `module`, `path`, `title`, `page`, `section`, `citation`, `text`, `context` та оцінки `score`, `dense`, `sparse`, `bm25`, `rerank`, `relevance`), `citations` (`n`, `valid`), `warnings` і `timings`.

## Вебінтерфейс

`kovcheg ui` запускає локальну вебсторінку (типово http://127.0.0.1:8501).

- **Ліва панель:** модулі з позначками цілісності (valid / unsigned / untrusted / INVALID), кількість документів і перемикачі режиму «лише пошук» та реранкінгу. Модулі зі станом INVALID типово не вибрано, і для них показано червоне попередження.
- **Відповідь:** виводиться потоково в міру генерування, з посиланнями `[n]`. Посилання, яке не відповідає жодному джерелу, позначено ⚠.
- **Джерела:** пронумеровані точно так, як у посиланнях, із документом, сторінкою, розділом, уривком і сусіднім текстом. Джерела, на які відповідь справді посилається, позначено.
- **Рядок стану:** які моделі активні (ембединги, реранкер, мовна модель) і чому модель вимкнено.
- **Мова:** типово українська, англійська — з `[ui] language = "en"`.

Щоб телефони й ноутбуки в тій самій мережі Wi-Fi могли користуватися одним комп'ютером із Ковчегом, задайте `[ui] host = "0.0.0.0"` і відкрийте `http://<machine-ip>:8501` на інших пристроях. Автентифікації немає, тому робіть це лише в мережі, яку контролюєте.

## Вимірювання якості пошуку

Створіть файл JSONL, у якому кожен рядок містить запитання та документ, що на нього відповідає:

```json
{"question": "How long should water be boiled?", "expected": "water.txt"}
{"question": "Код J18.9", "expected": ["medicine:icd10.pdf", "medicine:pneumonia.md"]}
```

`kovcheg eval questions.jsonl` повідомляє hit@1, hit@3, hit@k і MRR. Запускайте його до і після зміни налаштувань, моделей чи документів.
