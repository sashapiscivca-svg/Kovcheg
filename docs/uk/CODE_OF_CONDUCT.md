# Кодекс поведінки

[English](../../CODE_OF_CONDUCT.md)

Ковчег створюють для людей у скрутних ситуаціях. Ми очікуємо, що всі учасники в просторах цього проєкту будуть шанобливими, терплячими й конструктивними, виходитимуть із припущення про добрі наміри й пам'ятатимуть, що багато учасників пишуть не рідною мовою.

Цькування, образи, особисті чи політичні нападки, сексуалізовані висловлювання чи зображення, оприлюднення чужої приватної інформації та навмисне порушення роботи спільноти неприйнятні.

Повідомляйте про інциденти приватно супровідникам через канал, описаний у [SECURITY.md](SECURITY.md). Супровідники розглядають кожне повідомлення, зберігають конфіденційність особи того, хто повідомив, і можуть попередити або заблокувати учасників, які порушують ці правила.

Цей кодекс натхненний [Contributor Covenant](https://www.contributor-covenant.org/), версія 2.1.
