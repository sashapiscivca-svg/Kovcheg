# Code of conduct

[Українська](docs/uk/CODE_OF_CONDUCT.md)

Kovcheg is built for people in hard situations. We expect everyone in this project's spaces to be respectful, patient and constructive; to assume good faith; and to remember that many participants write in a second language.

Harassment, insults, personal or political attacks, sexualised language or imagery, publishing others' private information and deliberate disruption are not acceptable.

Report incidents privately to the maintainers through the channel described in [SECURITY.md](SECURITY.md). Maintainers review every report, keep the reporter's identity confidential, and may warn or ban participants who break these rules.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
